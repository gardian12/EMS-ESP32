How To Build
------------

WWWData.h is an auto-generated file located at src/ESP32React/WWWData.h

It doesn't exist in the repository yet because it's created during the web interface build process. The file is generated by the script progmem-generator.js, which converts the built web assets into a C++ header file for embedding in the firmware.

To generate it:

Build the web interface first: pio run -e build_webUI
Then build the firmware: pio run (this will run the progmem-generator as part of the build process)
After that, WWWData.h will contain the compressed web UI data as PROGMEM arrays, which the ESP32React library uses to serve the interface without external files.



BUILDING THE WHOLE PROJECT
---------------------------

python3 -m venv .venv
source .venv/bin/activate
pip install platformio
pio run
